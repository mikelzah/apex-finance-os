# Кубыш

Приложение для управления личным капиталом. Работает в браузере, ставится
на домашний экран, **данные хранятся только в вашем устройстве** и никуда
не отправляются: ни сервера, ни аккаунта, ни аналитики.

- Капитал, мгновенно доступные деньги и инвестиции на одном экране
- Цели с прогнозом закрытия и планом взносов
- Портфель: целевая структура против фактической
- Проценты по вкладам и счетам, включая ежедневную капитализацию
- Налог на проценты по ключевой ставке ЦБ
- Котировки Мосбиржи
- Светлая и тёмная темы

## Установка на iPhone

Открыть адрес в **Safari** → «Поделиться» → **На экран «Домой»**.

Именно Safari: другие браузеры на iOS ставить веб-приложения не умеют.
После установки приложение открывается во весь экран, без адресной строки,
и работает без сети.

## Первый запуск

Приложение не подставляет данные само и предлагает три пути: начать с нуля,
посмотреть на демо-данных или загрузить резервную копию. Демо-данные
вымышленные, их можно стереть в любой момент в разделе «Ещё».

## Резервная копия

Данные живут только в этом устройстве. Очистка данных браузера, удаление
приложения с домашнего экрана или потеря телефона стирают всё безвозвратно.
Синхронизации нет по построению.

«Ещё → Резервная копия → Сохранить копию» открывает системный лист: Файлы,
iCloud Drive, почта, мессенджер. Приложение напоминает о копии раз в две
недели — периодичность меняется в настройках.

Загрузка из копии заменяет данные целиком, а не дополняет их: слияние двух
разошедшихся журналов операций без общей истории даёт дубли, которые потом
руками не разобрать.

## Проценты — это модель, а не факт

Приложение не видит ваш банк. Начисление считается по ежедневному остатку,
восстановленному из операций, год фактический — 365 или 366 дней.
Расхождение с банком неизбежно: он считает по своим правилам, округляет
по-своему, пополнение может начинать работать со следующего дня, а ставка
по накопительному счёту меняется задним числом.

Поэтому операцию «Доход» приложение не создаёт само: в день капитализации
на главном экране появляется сумма и кнопка «Записать» — есть момент
сверить цифру с приложением банка до того, как она попадёт в капитал.

Раздел про налог — не налоговая консультация, а арифметика по открытой
формуле: 1 млн ₽ × максимальная ключевая ставка на 1-е число месяца.

## Котировки

Цены запрашиваются напрямую у Мосбиржи (`iss.moex.com`, публичный API без
ключа). Если запрос не проходит — это ограничение браузера, а не поломка:
последняя известная цена остаётся на месте, новую можно ввести руками
в карточке актива, всё остальное продолжает работать.

## Как это устроено

Сборки нет: чистые ES-модули, ноль зависимостей, ноль `node_modules`.
Браузер грузит файлы как есть.

```
index.html              оболочка
manifest.webmanifest    имя, иконки, режим standalone
sw.js                   офлайн-кэш
css/tokens.css          все значения оформления
css/app.css             оформление
fonts/                  Inter, подмножество 58 КБ
js/calc.js              расчётное ядро
js/store.js             хранилище IndexedDB
js/views/               экраны
data/demo.json          демо-данные
```

Локальный запуск:

```sh
npx http-server . -p 8080 -c-1
```

**После правки любого файла поднимите `VERSION` в `sw.js`.** Иначе на
устройствах останется старая закэшированная копия, и понять это по
внешнему виду невозможно — экран выглядит рабочим, просто старым.
